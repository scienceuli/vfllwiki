# Dokumentation

Die VFLL-Wissensdatenbank enthält auch Dokumentationen zu den Tools des VFLL, z.B. zum [KollTool](KollTool.md). Diese Dokumentation befindet sich im Verzeichnis `docs`.  Mithilfe des Tools [Mkdocs](Mkdocs.md) wird aus den [markdown](Markdown.md)-Dateien in dem Verzeichnis die Website [kolltooldocs.vfll.de](https://kolltooldocs.vfll.de) generiert.
