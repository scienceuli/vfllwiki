# Dokumentation

Die VFLL-Wissensdatenbank enthält auch Dokumentationen zu den Tools des VFLL, z.B. zum [[KollTool.md]]. Diese Dokumentation befindet sich im Verzeichnis `docs`.  Mithilfe des Tools [[Mkdocs.md]] wird aus den [[Markdown.md|markdown]]-Dateien in dem Verzeichnis die Website [kolltooldocs.vfll.de](https://kolltooldocs.vfll.de) generiert.
