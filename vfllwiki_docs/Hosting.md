Die Server, auf denen die VFLL-Anwendungen laufen, werden von _science and more_ betreut.

Alle Server werden von [[Netcup]] gehostet, zur Zeit (Okt. 2026) verteilt auf die Accounts von _science and more_ und VFLL.

### Übersicht der Server

| Alias   | Host                         | Function              | Customer         | Provider    |
| ------- | ---------------------------- | --------------------- | ---------------- | ----------- |
| backup  | backup.science-and-more.com  | Backup                | science and more | Netcup      |
| bbb     | bbb.science-and-more.com     | BigBlueButton Vfll    | Vfll             | Netcup Vfll |
| bohr    | bohr.science-and-more.com    | VfllCMS, Eventmanager | Vfll             | Netcup Vfll |
| euler   | euler.science-and-more.com   | KollTool, Memberadmin | Vfll             | Netcup Vfll |
| faraday | faraday.science-and-more.com | Eventmanager          | science and more | Hetzner     |
| gauss   | gauss.science-and-more.com   | VfllBlog              | Vfll             | Netcup      |
| hertz   | hertz.science-and-more.com   | Vfll Nextcloud        | science and more | Netcup      |

Die DNS-Records für die Subdomains der VFLL-Anwendungen werden bei [[all-inkl]] gehostet. 

Das Monitoring der Server ist unter https://monitor.sam-projekte.de  erreichbar.
